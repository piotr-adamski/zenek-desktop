# Roadmap

## Delivered in 0.2.0 preview

Scoped model tools, autonomous character history, private/shared interests and
hobbies, durable feedback/plans, a local notebook and a native searchable
conversation/development workspace. See the [changelog](../CHANGELOG.md).

## Next

Open priorities after 0.2.0, without scheduled promises:

- Validate clean installation on additional GNOME 50 distributions and document dependencies.
- Add an English UI/persona option.
- Evaluate long-term variety and self-model growth with opt-in synthetic sessions,
  preserving corrections and inference limits.
- Evaluate agenda quality, topic closure and hobby continuity over longer use;
  keep internal plans from producing repetitive invitations.
- Improve notebook backup/export together with encrypted memory controls.
- Package complete desktop integration; evaluate Flatpak and GNOME Extensions
  catalog distribution before claiming either is available.
- Improve account selection/recovery without silent model or paid API changes.

Propose concrete experiences through
[feature requests](https://github.com/piotr-adamski/zenek-desktop/issues/new/choose).
Use the private channel for security reports.
